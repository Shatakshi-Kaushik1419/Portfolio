# 🌐 Personal Portfolio Website

A simple and responsive personal portfolio website created using **HTML5 and CSS3**.

## 👩‍💻 About the Project

This project is a personal portfolio website for showcasing my profile,
skills, education, and contact information.

The website has a clean dark-themed design with a sidebar containing
profile and contact details and a main section for portfolio information.

## ✨ Features

- Personal profile section
- Profile picture
- Contact information
- Social media links
- About Me section
- Skills section
- Education section
- Navigation menu
- Dark-themed user interface
- Hover effects on skills and navigation links

## 🛠️ Technologies Used

- HTML5
- CSS3
